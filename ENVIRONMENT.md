# Environment Variables

Validated at process startup by `packages/config/src/env.ts` (Zod schemas
`apiEnvSchema` / `webEnvSchema`). **Production refuses to boot** if a
selected provider (storage/email/WhatsApp) is missing its required
credentials — see `assertProductionInvariants()` in that file.

Copy `.env.example` → `.env` (root, for running both apps together) or the
per-app `apps/api/.env.example` / `apps/web/.env.example` for running one
app standalone.

**Secret generation reminder:** every value marked "Secret? Yes" must be a
unique, random, production-specific value — never reuse a value from
`.env.example`, a dev secret, or a value shown in this repository's
history.
