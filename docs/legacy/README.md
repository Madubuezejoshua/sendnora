# Legacy documentation

These documents describe the previous manual invoicing product (customers, quotes, invoices, expenses,
recurring invoices) that this repository started as. Its code and data are preserved: the endpoints live
under `/api/legacy/v1` and its database tables are untouched. The documents are kept for reference and
are **not** maintained; they were written under the previous working name (the rename was applied mechanically), so statements about features may no longer match the current product.

The current product is Sendnaro, an automated transactional messaging and invoice API. Start at the
root [README.md](../../README.md).
